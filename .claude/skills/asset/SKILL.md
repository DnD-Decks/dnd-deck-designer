# /asset — art prompt + asset issue for a spell

Given a spell name or id, render its image-generation prompt from the template in this folder and upsert the matching `[asset]:` GitHub issue so an art contributor can pick it up.

Asset identity is **per unique spell, shared across classes** — `fire-bolt.png` serves both Wizard and Sorcerer decks. Never create per-class variants.

## Steps

### 1. Resolve the spell

- Kebab-case the argument (lowercase, spaces → `-`) to get a candidate id, e.g. `fire bolt` → `fire-bolt`.
- Look up that key in `src/data/spells/spells-level-*.json` (objects keyed by spell id).
- If no key matches, try a case-insensitive match against each entry's `name` field.
- **Still not found:** grep the spell files for partial matches on the argument, list the near-miss ids as suggestions, and stop. Do not create an issue.

### 2. Render the prompt

Fill `asset.template.prompt.md` (same folder as this file) with the spell's fields.
Everything above `## SCENE` is the shared house style — reproduce it **verbatim**, never reworded
per spell. Only the SCENE block is data-driven:

- `{{name}}`, `{{school}}` — verbatim from the JSON.
- `{{level_label}}` — `cantrip` when `level` is `0`, otherwise `level N spell`.
- `{{description}}` — the first 1–2 sentences of `description` (stop at the second `.`). Skip rules mechanics like saving throws where possible; keep the visual imagery.
- `{{damage_note}}` — when the spell has a `damage` field: `The visual centers on <damage.type joined with "/"> damage.` When it doesn't, remove the line entirely (no blank placeholder).

Strip the HTML comment header from the output.

### 3. Show the prompt

Print the rendered prompt in the chat inside a fenced code block, ready to copy-paste into ChatGPT.

### 4. Upsert the GitHub issue (idempotent)

Check for an existing open issue:

```sh
gh issue list --state open --label ASSET --search "[asset]: <name>" --json number,title
```

Match on the exact title `[asset]: \`<name>\` spell` (name in original casing).

- **No match:**

  ```sh
  gh issue create --title "[asset]: \`<name>\` spell" --label ASSET --body "<body>"
  ```

- **Match:** update instead of duplicating:

  ```sh
  gh issue edit <number> --body "<body>"
  ```

Issue body format:

```markdown
<!-- generated by /asset — do not edit by hand; re-run `/asset <id>` to regenerate -->

## Asset ID

`<id>`

## Card data snapshot

| Field | Value |
| --- | --- |
| Name | <name> |
| School | <school> |
| Level | <level> |

## Image-generation prompt (paste into ChatGPT)

​```
<rendered prompt>
​```

## Acceptance criteria

- [ ] PR adds `public/art/<id>.png` — vertical (portrait) ratio, ≥ 1024 px tall
- [ ] PR body references `Closes #<this issue number>`
```

### 5. Report

Print the issue URL and whether it was created or updated.
